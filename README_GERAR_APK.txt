# JARVIS — APK automático

Este projeto está preparado para compilação Android pelo GitHub Actions.

## Como gerar o APK

1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta para o repositório.
3. Abra a aba **Actions**.
4. Execute **Build JARVIS APK**.
5. Ao terminar, abra a execução concluída e baixe o artefato **JARVIS-APK**.

O workflow usa o Buildozer Action e gera um APK debug para Android.
